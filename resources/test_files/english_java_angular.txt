Senior Software Engineer (Angular)

We are seeking senior-level (Level 3) Software Engineers to design, develop, and support scalable enterprise applications. This role is ideal for a full-stack engineer with strong Angular expertise and hands-on Java experience who enjoys working in an Agile/SAFe environment.

Engineers will support new feature development, product enhancements, and production support while collaborating closely with cross functional teams.

Responsibilities

Design, build, and support reliable, secure, and scalable software solutions
Develop front-end applications using Angular and contribute to Java-based backend services
Participate actively in Agile/SAFe ceremonies (standups, refinement, retrospectives, sprint and PI planning)
Lead feature-level discussions and contribute to technical design decisions
Write clean, maintainable code and participate in code reviews
Contribute to CI/CD pipelines, automated testing, and quality standards
Troubleshoot and resolve complex production issues
Create clear technical documentation and design artifacts as needed
Mentor and support junior and mid-level engineers
Track work, status, and issues in a ticketing or tracking system
Clearly communicate technical concepts to both technical and non-technical stakeholders
Required Qualifications (Level 3)

3-5+ years of professional software engineering experience
Strong experience building modern applications with Angular
Strong Java development skills; comfortable writing and running Java code independently
Experience working in Agile or SAFe environments
Solid understanding of software design principles and best practices
Experience with RESTful services, APIs, and enterprise application development
Ability to work independently, manage priorities, and deliver high-quality work
Strong problem-solving, communication, and collaboration skills
Nice to Have

Experience with Spring or Spring Boot
CI/CD pipelines and automated testing experience
Experience producing technical diagrams or design documentation
Experience supporting production systems
Interview Process

Technical interview (~90 minutes) including a live Java coding exercise using an IDE of your choice
